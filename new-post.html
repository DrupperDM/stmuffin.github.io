* INICIAR SESIÓN

Créalo en GitHub → Settings → Developer settings → Fine-grained tokens. Dale acceso solo a este repositorio y permiso de "Contents: Read and write". No uses tu contraseña de GitHub, nunca pidas eso aquí.
Sobre esto: esta página es estática — no hay un servidor "detrás" que verifique un usuario y contraseña. El token de arriba hace esa función: es tu llave personal para escribir en tu repositorio. Se guarda solo en la memoria de esta pestaña (sessionStorage) y desaparece al cerrarla — nunca se sube a GitHub ni se envía a ningún otro lugar más que a la API oficial de GitHub. Si alguien más abre esta página sin tu token, simplemente no podrá publicar nada: GitHub rechazará la petición.
